# ZASI API reference

The authoritative contract is generated by FastAPI at
`GET /api/v2/openapi.json` after authentication. The checked-in implementation
and tests live in `backend/app.py`, `src/control_plane/`, and `tests/`.

## Authentication

1. `POST /api/v2/sessions` with the environment-supplied bootstrap key.
2. Keep the returned bearer token in process memory only.
3. Send `Authorization: Bearer <token>` to every v2 resource and SSE stream.
4. Revoke with `POST /api/v2/sessions/revoke`; revoked or expired sessions are
   rejected.

The server resolves tenant, principal, device, and scopes. Client-supplied
tenant or principal fields are not authorization inputs.

## Read and govern

| Method | Route | Purpose | Side effect |
|---|---|---|---|
| GET | `/health/live` | Process liveness | none; intentionally public |
| GET | `/health/ready` | Dependency/schema readiness | none; intentionally public |
| GET | `/api/v2/capabilities` | Code-owned capability manifests | none |
| GET | `/api/v2/snapshot` | Authoritative scoped state | none |
| GET | `/api/v2/events` | Tenant-scoped SSE replay/resync | none |
| POST | `/api/v2/intents` | Store untrusted typed intent | audited |
| POST | `/api/v2/intents/{id}/plan` | Create immutable plan | audited; never executes |
| GET | `/api/v2/plans/{id}` | Read a scoped plan | none |
| POST | `/api/v2/plans/{id}/approve` | Approve exact digest where enabled | audited |
| POST | `/api/v2/plans/{id}/run` | Broker an approved action | idempotent and audited |
| GET | `/api/v2/runs/{id}` | Read run/evidence | none |
| POST | `/api/v2/runs/{id}/cancel` | Cancel a queued/local run | audited |

R0/R1 direct calls use `POST /api/v2/tools/preview` and
`POST /api/v2/tools/call` with a bounded typed body and `Idempotency-Key`.
Risk-bearing direct tool calls are rejected with `PLAN_REQUIRED`.

`GET /api/v2/audit` returns `tenant_id`, `records`, and `next_cursor`.
The cursor is `created_at|audit_id`; pass it as `after` to request the next
stable page. A null cursor means that the page is empty. The older timestamp-only
cursor is accepted only for migration compatibility.

## Evidence, artifacts, memory, and devices

- `GET /api/v2/evidence/{id}` returns immutable provenance and result metadata.
- `POST /api/v2/evidence/{id}/supersede` appends a correction; the reference
  profile cannot promote an operator correction to `verified`.
- `POST /api/v2/artifacts` stores bounded content in quarantine and returns a
  digest; it never exposes a filesystem path.
- `POST /api/v2/cad/analyze` and `POST /api/v2/vision/analyze` currently create
  truthful `unavailable` evidence because no parser/model adapter is enabled.
- `POST /api/v2/mobile/pair` or `POST /api/v2/devices` creates a short-lived
  one-time challenge. `POST /api/v2/mobile/{device_id}/approve` consumes it;
  `POST /api/v2/devices/{device_id}/revoke` invalidates device sessions.
- `GET /api/v2/devices/{device_id}/telemetry` reports unavailable in the
  reference profile; it does not fabricate hardware readings.
- Briefings and memory are durable and scope-checked. Missing briefing sources
  remain missing/unavailable.

## Sequences

`POST /api/v2/sequences` creates a server-IDed draft. Validate it before
`POST /api/v2/sequences/{id}/run`; each step is resolved through the same
registry/policy/broker and the sequence revision is digest-bound. Sequence
events are available from `GET /api/v2/sequences/{id}/events`.

## MCP and compatibility

`POST /api/v2/mcp` supports JSON-RPC `initialize`, `tools/list`, and governed
`tools/call`. Discovery is read-only; calls use the same broker and
idempotency path. The old `/api/mcp` path is retired. `/api/status` and
`/api/telemetry` are authenticated compatibility disclosures; GET mutation,
direct execution, and runtime-upgrade routes return `410`.

The primary SSE stream is `GET /api/v2/events`. `after` is optional when the
client sends `Last-Event-ID` or `X-ZASI-Event-Cursor`; if multiple cursor
sources are present they must agree. A retention gap emits `resync.required`,
after which the client must replace local state from `/api/v2/snapshot`.

## Error and retry rules

Errors use `{error: {code, message, request_id, retryable, details}}` and do not
expose stack traces, SQL, paths, or secrets. JSON bodies are bounded and typed;
malformed JSON is `400 MALFORMED_JSON`. Retry only with the same idempotency key
when the operation contract allows it. An unknown external side effect must be
reconciled before retry; external egress is disabled in the reference profile.

Historical prototype classes under `src/` may still be imported by research or
legacy tests. Their names and docstrings are not API capability evidence and
they are not imported by the authoritative `backend.app` process.
